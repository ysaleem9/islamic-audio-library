# المكتبة الصوتية العلمية — موقع دروس دينية صوتية مجاني 100%

موقع إسلامي حديث وسريع لنشر الدروس الصوتية لشيخ أو متحدث واحد، مرتبة كـ **سلاسل علمية** و**دروس مفردة وخطب**، مع **لوحة تحكم مدمجة** وتكامل مباشر مع **Internet Archive (`archive.org`)** للتخزين الصوتي المجاني بلا حدود وبدون بطاقة بنكية.

## أبرز المميزات
- **تصميم عربي (RTL) هادئ ومريح للقراءة** بخطي `Amiri` و `IBM Plex Sans Arabic`.
- **مشغل صوتي ثابت أسفل الشاشة** يعمل أثناء التنقل بين الصفحات مع:
  - حفظ تلقائي لآخر ثانية توقفت عندها في كل درس.
  - التحكم بسرعة التشغيل (`1x` إلى `2x`).
  - تقديم وتأخير 15 ثانية + تشغيل تلقائي للدرس التالي في السلسلة.
  - مؤقت النوم (15 / 30 / 60 دقيقة) + تحميل مباشر MP3.
- **لوحة تحكم محمية بتسجيل دخول (`/admin`)**:
  - إدارة السلاسل العلمية والدروس المفردة وإعدادات الشيخ والموقع.
  - **استيراد ذكي من `archive.org`**: الصق رابط أي عنصر على أرشيف الإنترنت لاستخراج كل ملفات MP3 واستيراد سلسلة كاملة بضغطة زر.
  - **رفع مباشر من لوحة التحكم إلى `archive.org`** (عبر مفاتيح S3 المجانية).
- **يعمل فوراً محلياً بدون أي إعداد مسبق** (عبر `data/db.json`)، ويتحول تلقائياً إلى **Supabase** عند النشر المجاني على **Vercel**.

## التشغيل المحلي السريع
```bash
npm install
npm run dev
```
ثم افتح:
- الموقع: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin` (الافتراضي للتجربة المحلية: `admin` / `admin123`)

## النشر المجاني 100% (بدون بطاقة بنكية)
1. **الصوتيات:** أنشئ حساباً مجانياً على [archive.org](https://archive.org) (واختيارياً احصل على مفاتيح الرفع المباشر من `https://archive.org/account/s3.php`).
2. **قاعدة البيانات:** أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com) وشغّل الملف `supabase/schema.sql` في SQL Editor.
3. **الاستضافة:** ارفع المشروع على GitHub واربطه بـ [vercel.com](https://vercel.com) مع إضافة متغيرات البيئة الموضحة في `.env.example`.
